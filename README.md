# 澄心瑜伽 · 私教全流程管理（体验课测评 / 排课 / 续费 / 转教练交接）

城市瑜伽馆私教业务的一体化页面：**会员、顾问、教练** 三个角色围绕 **同一套训练记录** 协作 ——
从体验课预约、教练测评、购课排课，到每节课的课后记录、请假改期、不适上报、**转教练交接**与续费跟进，
每一次疼痛、缺勤、训练效果和课程调整都会沉淀为后续排课与续费沟通的依据。

**转教练交接（本题新增）**：会员认为教练风格不合适时，顾问发起结构化交接 —— 页面自动整理
**训练目标、已完成课程、疼痛变化、会员偏好与投诉原因**；新教练接手前必须阅读并确认交接记录，
首节试课结束后填写适配反馈；试运行期间顾问跟踪会员满意度与新教练反馈并定夺是否稳定转入；
仍不适配时页面建议 **退课 / 转团课 / 换目标方案**（或回原教练），双方沟通记录全程保留。

- 技术栈：Vue 3 + TypeScript + Pinia + Vue Router + Vite（纯前端 SPA，数据存 localStorage，可一键重置演示数据）
- 项目类型：前端（无后端业务接口，故不提供 Swagger/OpenAPI）

## 快速启动

### 方式一：Docker（一键）

```bash
docker compose up --build
# 打开 http://localhost:8080
```

也可手动：`docker build -t yoga-pt-studio . && docker run -p 8080:80 yoga-pt-studio`

### 方式二：本地开发

```bash
npm install
npm run dev        # http://localhost:5173
```

### 生产构建与预览

```bash
npm run build      # 类型检查 + 构建到 dist/
npm run preview    # http://localhost:4173
```

## 验证方式（建议演示路径）

1. **体验转化**：顾问登录 →「安排体验课」为李敏选教练（介意异性 → 仅显示女教练，按目标推荐）→ 教练苏晴/林岚登录 → 周课表点体验课 → 填课后记录 → 填测评（体态评估/动作限制/课程建议/风险提示/推荐套餐，提交即锁定）。
2. **购课排课**：会员张倩登录 → 主页确认购买推荐套餐 → 自动生成课包、每周排课、请假规则与续费提醒基线。
3. **上课记录**：教练林岚登录 → 周课表点王晓彤的待上课 → 填完成动作/体感/疼痛变化/家庭练习 → 下节课重点自动同步。
4. **异常闭环**：
   - 会员王晓彤 →「请假与申请」上报膝盖不适 → 教练林岚在会员档案中做「课程调整」→ 顾问在「异常工单」办结；
   - 教练周远在周课表点「请假」→ 顾问在工单中为何静的课改期补课。
5. **转教练交接（本题主流程）**：
   - 会员孙悦 →「请假与申请 → 申请换教练」提交原因（种子数据已提交并生成工单）；
   - 顾问陈曦 →「异常工单」点「发起转教练交接流程」（或直接进入「转教练交接」）→ 页面自动整理孙悦的**训练目标、3 节已完成课程、疼痛变化、会员偏好（希望女教练）与投诉原因** → 选择苏晴并发起；
   - 教练苏晴登录 → 周课表横幅或「交接任务」→ **阅读交接记录并确认接手**（填写接手计划，未来课程随即转入其名下课表，首节试课重点自动更新）；
   - 苏晴在周课表完成孙悦的首节试课（填课后记录）→ 回到「交接任务」**填写首课适配反馈**（适配度/会员课堂反应/后续计划/建议）；
   - 顾问陈曦 →「转教练交接」→ 试运行期间**记录会员满意度与新教练反馈**（经营看板也有试运行一览）→ **定夺**：适配良好选「稳定转入」，工单自动办结；
   - **仍不适配分支**：适配度 ≤4 / 建议终止 / 满意度 ≤5 时，定夺区出现红色提示并建议 **退课 / 转团课 / 换目标方案**（也可回原教练）——退课/转团课会结束课包并取消未来课程，换目标方案会更新会员目标并过渡下节课重点，回原教练则把课程退还给原教练；
   - 全程**双方沟通记录**（会员/新教练/顾问同一线程）保留在交接单中，会员在主页可见进度并留言。
6. **续费**：顾问登录 → 看板「续费提醒」→ 进入赵磊的会员 360° →「基于训练记录生成要点」（出勤、疼痛趋势、教练备注，而非只看剩余课时）→ 保存跟进；选「已续费」则新课包自动衔接。
7. **边界**：顾问在会员 360° 看到的教练专业档案为只读锁定卡（🔒），不可编辑；教练的测评与风险提示不会变成销售话术。
8. 右上角「重置演示数据」可随时恢复初始场景。

## 目录结构

```
src/
  types/index.ts        # 领域模型（预约/测评/课包/排课/记录/工单/续费/转教练交接/时间线）
  data/seed.ts          # 演示种子数据（覆盖六类异常场景 + 进行中的转教练交接）
  stores/               # Pinia：auth（登录）+ data（全部业务动作与看板计算）
  views/
    member/             # 预约体验课、我的主页（课包/课表/购课/转教练进度）、训练记录、请假与申请
    coach/              # 周课表、会员档案、课后记录、体验测评、交接任务（确认接手/适配反馈）
    consultant/         # 经营看板、安排体验课、异常工单、转教练交接、会员 360°（续费跟进）
  components/           # 训练时间线（三方共享）、专业档案（锁定只读）、课包卡
```
